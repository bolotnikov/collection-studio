---
title: 'Почему десктоп и Electron'
description: 'Десктоп объединил интерфейс, локальный CLI и файлы проектов.'
---

Я выбрал десктоп по двум причинам:

- **Проще инфраструктура.** Проекты и изображения хранятся на компьютере, отдельный сервер для запуска приложения не нужен.
- **Локальный Codex CLI.** Генерация использует уже установленный инструмент и вход через ChatGPT.

Electron объединил интерфейс на веб-технологиях с запуском локальных процессов. Для командной работы этот подход можно развить в веб-сервис — под требования команды и доступную инфраструктуру.
