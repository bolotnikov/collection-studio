---
title: 'Почему классификация, а не обучение'
description: 'Классификация даёт явные правила для планирования коллекций.'
---

import Callout from '../../../components/Callout.astro';

Я описал исходные карточки через категории, фон, опору, узор, цвет и положение в наборе. По этим данным программа заранее определяет состав будущей коллекции и подбирает примеры.

160 карточек — небольшая база для обучения собственной модели. Я выбрал классификацию: она позволяет использовать готовую модель, а состав коллекции рассчитывать по явным правилам.

<Callout title="Решение">
  Детерминированное применение признаков и проверки.
</Callout>
