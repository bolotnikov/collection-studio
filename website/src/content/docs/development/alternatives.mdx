---
title: 'Какие решения сравнивали'
description: 'Подходы сравнивали по управляемости, доступности и удобству работы.'
---

Были рассмотрены Asset Studio, Vehicle Asset Generator, ComfyUI, IP-Adapter и рабочие процессы Scenario. Сравнивались работа с референсами, повторяемость генерации и удобство для продюсера.

| Подход                 | Полезная идея для проекта                |
| ---------------------- | ---------------------------------------- |
| Готовые сервисы        | Простой интерфейс и повторяемые сценарии |
| ComfyUI                | Явно заданные этапы генерации            |
| IP-Adapter             | Отдельная роль текста и референсов       |
| Десктопные инструменты | Работа с локальными процессами и файлами |

Для проекта был выбран короткий маршрут: тема → набор → правка → экспорт.
