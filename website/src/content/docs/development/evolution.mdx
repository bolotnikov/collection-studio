---
title: 'Как менялся процесс'
description: 'Наблюдения первых запусков уточнили планирование и правила генерации.'
---

Во время работы требования уточнялись по результатам генерации. Конкретное наблюдение превращалось в изменение процесса.

| Наблюдение                                | Изменение процесса                                               |
| ----------------------------------------- | ---------------------------------------------------------------- |
| Край предмета обрезался                   | Заданы портретная композиция и место для целого силуэта          |
| Свет становился слишком кинематографичным | Закреплён приоритет стиля исходных карточек                      |
| Карточки слабо сочетались                 | Планирование состава, цветов и фонов перенесено перед генерацией |
