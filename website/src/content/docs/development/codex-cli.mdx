title: 'Почему Codex CLI'
description: 'Локальный Codex CLI позволил работать без отдельного бюджета на API.'
---

import Callout from '../../../components/Callout.astro';

В моём распоряжении не было бюджета на эксперименты через API, поэтому я выбрал локальный Codex CLI с входом через ChatGPT.

Приложение запускает CLI на моём компьютере:

1. Передаёт задачу и референсы.
2. Получает изображение и данные ответа.
3. Сохраняет результат в проекте.

<Callout title="Использование">
  Генерация расходует доступные лимиты Codex.
</Callout>
