Были проверены:

- наличие анализа для всех исходных изображений;
- десять разных карточек в каждом наборе;
- правильность ссылок на примеры;
- совместимость категории и признаков.

Спорные случаи были просмотрены вручную. Например, карточка с лебединым прудом была отнесена к окружению по композиции всей сцены. Исправление сохранено вместе с первоначальным ответом модели.
