Программа рассчитывает средний состав по подходящим исходным наборам. Каждый набор имеет одинаковый вес.

Для обычного режима расчёт выглядит так:

1. Взять предметные карточки категорий 1–4.
2. Пересчитать доли каждого набора на десять мест.
3. Найти средние доли категорий и сочетаний признаков.
4. Подобрать целое число карточек для новой коллекции.

Так программа учитывает и наборы из десяти предметов, и смешанные наборы.
