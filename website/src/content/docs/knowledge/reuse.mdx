Готовая база входит в приложение. При создании нового набора программа использует уже разобранные изображения.

- Для проекта сохраняется копия базы и правил на момент старта.
- При изменении исходника обновляются связанные с ним данные.
- История созданных коллекций хранит условия их запуска.
