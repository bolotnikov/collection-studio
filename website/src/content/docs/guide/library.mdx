---
title: 'Найти референсы в базе'
description: 'Фильтры помогают найти нужные примеры в базе.'
---

import Shot from '../../../components/Shot.astro';

Раскройте **База знаний → Карточки**.

1. Выберите категорию, чтобы сузить список примеров.
2. Нажмите **Паттерны** и выберите нужные признаки.

Счётчик показывает число подходящих карточек. Нажатие на изображение открывает его анализ; **Сбросить фильтры** возвращает полный список.
