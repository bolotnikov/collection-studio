import Shot from '../../../components/Shot.astro';

При нескольких вариантах сначала выберите нужный набор для сдачи.

1. Нажмите **Экспорт набора** и укажите место для архива.
2. При необходимости отдельно сохраните **Журнал работы**.

В архив входят:

- десять PNG-карточек 430×480;
- исходные изображения выбранных версий;
- история, общий лист и данные запуска.
