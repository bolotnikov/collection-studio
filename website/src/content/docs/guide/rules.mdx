---
title: 'Изменить правила отрисовки'
description: 'Общие правила отрисовки задают художественную подачу новых наборов.'
---

import Shot from '../../../components/Shot.astro';

Откройте **База знаний → Стиль** и нажмите **Редактировать правила**.

1. Внесите изменения: одна строка — одно правило.
2. Нажмите **Сохранить правила**.

Общие правила применяются к новым наборам. У каждого уже созданного проекта остаётся собственная сохранённая версия правил.
