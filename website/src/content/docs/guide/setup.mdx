Для работы нужны установленный Codex CLI, вход через ChatGPT и готовая библиотека референсов.

<ProjectLinks />

1. Откройте **Настройки**.
2. Выберите модель генерации. По умолчанию используется **GPT-6.1 Terra**.
3. Нажмите **Проверить подключение**.

Путь к исполняемому файлу можно указать в блоке **Путь к Codex CLI**.
