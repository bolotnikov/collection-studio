## Требования к запуску

- **Система:** Mac с macOS 13 Ventura или новее, Intel или Apple Silicon.
- **Комплект:** Electron и библиотека референсов входят в приложение. Node.js и npm нужны для сборки из исходников.
- **Первый запуск:** подпись ad-hoc без нотарификации Apple. macOS может запросить [подтверждение запуска](https://github.com/bolotnikov/collection-studio/blob/main/docs/MACOS_FIRST_LAUNCH.md).

Для генерации дополнительно нужны:

- установленный Codex CLI и вход через ChatGPT;
- доступ к выбранной модели и инструменту изображений;
- доступные лимиты Codex и интернет.

Библиотеку можно просматривать сразу после открытия приложения.

## Проверенная среда

- **Локально:** macOS Sequoia 15.7.7, Apple Silicon (arm64); проверка типов, линтер, автоматические тесты и сборка.
- **Codex CLI:** адаптер проверен с версией `0.167.0-alpha.4.1`.
- **CI:** тесты и сборка кода на Linux; тесты и упаковка приложения на macOS ARM64.
- **Релиз 0.1.2:** скачанный ZIP проверен по SHA-256; проверены подпись, версия, ресурсы и обе архитектуры.

## Подключение генерации

1. Откройте **Настройки**.
2. Выберите модель генерации. По умолчанию используется **GPT-6.1 Terra**.
3. Нажмите **Проверить подключение**.

Путь к исполняемому файлу можно указать в блоке **Путь к Codex CLI**.
