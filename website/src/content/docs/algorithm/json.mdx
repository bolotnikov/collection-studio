JSON — текстовый формат с именованными полями. Через него программа передаёт модели тему и требования и получает описание коллекции.

После ответа программа проверяет:

- обязательные поля;
- число предметов;
- номера карточек и связи с планом.

При генерации само изображение сохраняется отдельным файлом.
