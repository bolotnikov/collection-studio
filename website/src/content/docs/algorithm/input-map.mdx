---
title: 'Связать инструкцию с изображениями'
description: 'Номера и роли привязаны к фактически приложенным изображениям.'
---

import InfoGrid from '../../../components/InfoGrid.astro';

В каждом запросе изображения пронумерованы. Инструкция объясняет роль каждого вложения: откуда брать композицию, стиль и основу для правки.

Программа составляет этот список заново для каждой карточки. Например, при доработке он может выглядеть так:

<InfoGrid
  title="Пример ролей вложений"
  items={[
    {
      title: 'Изображение 1',
      text: 'Выбранная версия карточки — основа для изменения.',
    },
    {
      title: 'Изображение 2',
      text: 'Пример нужной композиции из базы знаний.',
    },
    {
      title: 'Изображение 3',
      text: 'Лист категории с допустимыми вариантами.',
    },
  ]}
/>
