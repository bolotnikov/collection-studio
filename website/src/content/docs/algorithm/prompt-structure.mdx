Запрос подробно описывает желаемое изображение. Его части помогают модели связать задачу с приложенными примерами.

При доработке программа также указывает, что изменить и какие детали сохранить. Структура опирается на [руководство OpenAI Cookbook по GPT Image](https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide). Текст запроса сохраняется с версией.
