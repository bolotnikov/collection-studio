---
title: 'Попросить модель придумать коллекцию'
description: 'Модель придумывает десять предметов по готовому плану коллекции.'
---

Модель получает тему, пожелания, десять подготовленных мест и примеры из базы. В ответ предлагает:

- название и общую идею коллекции;
- десять предметов;
- описание изображения для каждого предмета;
- единый стиль набора.

Программа проверяет число предметов и соответствие плану. При ошибке в структуре запрашивает уточнение в пределах заданного лимита.
