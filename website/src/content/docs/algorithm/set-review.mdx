---
title: 'Проверить отношения внутри набора'
description: 'Общая проверка анализирует выбранные изображения в сетке 5×2.'
---

При включённой общей проверке модель получает все выбранные карточки на одном листе 5×2. Она оценивает их сочетание и указывает конкретные изображения для правки.

1. Собрать общий лист.
2. Проверить цвета, фоны и связи карточек.
3. Исправить отмеченные изображения в пределах лимита.
4. Собрать и проверить обновлённый лист.

Например, лимит **2** позволяет выполнить два раунда исправлений и три проверки: начальную и по одной после каждого раунда.
