Детерминированная часть — это правила, по которым программа строит и проверяет коллекцию. При одинаковых исходных данных она выполняет одинаковые расчёты.

Программа определяет состав набора, требования к карточкам, подбор примеров и лимиты запросов. Модель придумывает предметы, рисует их и при включённой проверке анализирует композицию.

Сохранённый план используется при продолжении проекта.
