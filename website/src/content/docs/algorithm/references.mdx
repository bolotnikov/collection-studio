Для каждой карточки программа подбирает подходящие изображения из базы:

1. Выбирает её категорию.
2. Проверяет обязательные признаки композиции.
3. Сравнивает предметы, материалы и другие описания.
4. Собирает примеры для запроса.

Основой служат оригинальные карточки. Одобренные пользователем изображения дополняют библиотеку.
