Программа создаёт все десять карточек через общую очередь. Сейчас одновременно могут выполняться два задания.

1. Свободный исполнитель берёт следующую карточку.
2. Программа учитывает попытку в общем лимите.
3. Модель создаёт изображение.
4. Результат сохраняется как отдельная версия.
