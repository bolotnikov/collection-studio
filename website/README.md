# Сайт документации Collection Studio

Русскоязычный сайт на Astro, Starlight и MDX. Пять разделов объединяют короткие темы о разработке, работе с программой, базе знаний, алгоритме и примерах.

Оформление включает тёмную тему по умолчанию и светлую тему с белым фоном. Зелёный акцент взят из логотипа приложения. Поиск, навигация и переключение темы помогают читать материалы.

## Локальный просмотр

В корне репозитория выполните:

```sh
npm ci --prefix website
npm run docs:dev
```

Откройте адрес, который напечатает Astro, обычно `http://127.0.0.1:4321/`. Для установки зависимостей используйте актуальную версию Node.js и npm. Скрипты сайта запускаются через включённый в пакет Node.js 24.

Команды для работы с готовым сайтом:

```sh
npm run docs:build
npm run docs:check
npm run docs:preview
```

Сборка сохраняется в `website/dist/`. Публичный адрес: [bolotnikov.github.io/collection-studio](https://bolotnikov.github.io/collection-studio/).

## Публикация через GitHub Actions

1. Внесите изменения в `website/` и отправьте коммит в `main`.
2. Откройте выполнение `Website Pages` в [GitHub Actions](https://github.com/bolotnikov/collection-studio/actions).
3. Дождитесь успешных заданий `build` и `deploy`.

Процесс устанавливает зависимости из `website/package-lock.json`, проверяет форматирование, типы, сборку, локальные ссылки, якоря и изображения. Публикация выполняется через GitHub Pages с источником GitHub Actions. Pull request запускает проверки без публикации. Процесс можно повторно запустить вручную из Actions.

Переменная `DOCS_SITE` задаёт домен, а `DOCS_BASE` — путь сайта. Для проверки опубликованного адреса локально выполните:

```sh
DOCS_SITE=https://bolotnikov.github.io DOCS_BASE=/collection-studio/ npm run docs:build
DOCS_BASE=/collection-studio/ npm run docs:check
DOCS_BASE=/collection-studio/ npm run docs:preview
```

После такой сборки локальный адрес включает `/collection-studio/`. Без переменных сайт собирается для корневого пути `/`.

## Где редактировать материалы

- `src/content/docs/` — страницы тем и разделов на русском.
- `src/data/chapters.js` — порядок тем и данные навигации.
- `src/components/` — главная страница, оформление разделов, схемы, указатели и галереи.
- `src/styles/handbook.css` — темы, шрифты и адаптивная вёрстка.
- `src/data/catalog-statistics.json` — сводная статистика базы знаний.
- `public/media/` — подготовленные примеры и скриншоты.

Русская версия открывается по корневому адресу сайта. Настройки Starlight позволяют добавить другие языки позже. Страницы сгруппированы в разделы и темы.

## Откуда взяты изображения

- Четыре коллекции и версии планетохода взяты из сохранённых результатов генерации.
- Скрипт `scripts/prepare-media.mjs` создаёт WebP из выбранных проектов и рассчитывает сводную статистику. Переменная `HANDBOOK_RUNS_DIR` задаёт путь к локальным проектам для подготовки этих файлов.
- Обычная сборка использует готовые изображения из репозитория.
- Скриншоты сняты в текущем локальном Electron-приложении. На них видны активные проекты и загруженные изображения базы знаний.
- Стрелки и номера добавлены отдельным слоем SVG; номера соответствуют действиям в инструкции.
- При съёмке формы заполнялись как черновики, затем очищались. Окно удаления закрыто через отмену.
- На главной странице и обложках показаны шляпа из вестерна, конверт из детективного набора и посадочный модуль из научной фантастики: три разных сета и категории 1, 3 и 4.
- На странице планетохода сравниваются сохранённые версии 1 и 3: земной и лунный ландшафт.

## Редактура и иллюстрации

Каждая тема раскрывает одну мысль. Подзаголовок кратко передаёт её суть, последовательность действий оформляется списком. Решения автора описаны от первого лица.

Инфографика выбирается по смыслу: сравнение вариантов, состав базы, частоты позиций, очередь генерации или ветвление проверки. Часть тем объясняется текстом. Скриншот паузы добавляется при появлении такого состояния в текущем проекте; инструкция уже описывает оба действия.

## Источники текста

Текущее поведение сверяется с кодом, настройками и сохранёнными примерами. Основные материалы:

- `docs/COMPOSITION_ONLY_WORKFLOW.md` — создание набора и проверки композиции;
- `docs/IMAGE_PROMPTING.md` — требования к запросам изображений;
- `docs/KNOWLEDGE_CATALOG.md` — подготовленная база знаний;
- `docs/ENVIRONMENT_BACKGROUNDS.md` — фоны и окружение;
- `docs/ART_AND_RESEARCH.md` — графика и исследование;
- словарь признаков, визуальный каталог и сохранённые проекты.

Исходная графика задаёт стиль. Рекомендации OpenAI Cookbook помогают составлять запросы и инструкции доработки; ссылки на руководство есть в соответствующих темах.

Планы развития выделены отдельно: API, другие модели, MCP к ComfyUI и командный веб-сервис.

## Проверка изменений

```sh
npm run typecheck --prefix website
npm run lint --prefix website
npm run docs:build
npm run docs:check
```

Проверка готового сайта охватывает:

- локальные ссылки, якоря и изображения;
- язык страниц и длину тем;
- десять карточек в каждом примере;
- согласованность сводной статистики.

Вёрстка и обе темы проверяются отдельно в изолированном браузере Codex. Сайт собирается из собственных зависимостей и подготовленных публичных материалов.
