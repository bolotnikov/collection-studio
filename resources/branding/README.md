# Графика Collection Studio

Основа логотипа — персонаж с официальной [иконки Playrix](https://playrix.com/favicons/favicon.ico). Для Collection Studio он перерисован с помощью генерации изображений и дополнен короткой лентой из трёх картинок.

Исходные материалы:

- Прозрачное изображение 1254×1254 служит основой для всех размеров логотипа.
- `icon-generation.json` хранит точный запрос генерации и адрес исходной иконки.
- Скачанный оригинал содержит размеры 48×48, 32×32 и 16×16 и сохранён в локальном каталоге `local-sources/research/branding/`.

## Подготовка файлов

На macOS выполните в корне репозитория:

```sh
npm run prepare:icon
```

Скрипт сохраняет прозрачность, обрезает пустые края, размещает рисунок по центру с отступами и уменьшает его до нужных размеров. Исходное изображение сохраняется отдельно.

Результаты:

- `resources/icon.icns` — иконка macOS с размерами от 16 до 1024 пикселей.
- `resources/branding/collection-studio-logo.png` — логотип приложения 256×256, включаемый в сборку Vite.
- `website/public/logo.png` — тот же логотип для шапки сайта.
- `website/public/favicon.png` — иконка вкладки браузера 64×64.
- `website/public/apple-touch-icon.png` — иконка 180×180 для мобильных устройств Apple.

Сборка сайта использует готовые файлы из репозитория.
