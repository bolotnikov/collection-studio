# Первый запуск Collection Studio на Mac

Для приложения нужен **Mac с macOS 13 Ventura или новее**. Универсальная сборка работает на Intel и Apple Silicon; требование к версии системы задаёт [Electron 45](https://www.electronjs.org/docs/latest/breaking-changes).

## Скачать и открыть

1. Скачайте [Collection Studio для Mac](https://github.com/bolotnikov/collection-studio/releases/latest/download/Collection-Studio-mac-universal.zip).
2. Распакуйте ZIP.
3. Перенесите `Collection Studio.app` в **Программы / Applications**.
4. Откройте приложение.

В архив входят приложение, Electron, библиотека референсов и краткая инструкция `START-HERE.txt`. Для генерации изображений понадобится [подключить Codex CLI](#подключить-codex-cli).

## Подтвердить запуск в macOS

Сборка использует локальную подпись ad-hoc без нотарификации Apple. При первом открытии macOS может попросить подтвердить запуск в настройках безопасности.

1. Попробуйте открыть **Collection Studio.app**. Если появилось сообщение о непроверенном разработчике или невозможности проверить приложение, нажмите **Готово / Done**.

   ![Пример уведомления macOS о проверке приложения](https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/macos-sequoia-app-not-opened-could-not-verify-free-from-malware.png)

2. Если вы доверяете скачанному файлу, откройте ** → Системные настройки / System Settings → Конфиденциальность и безопасность / Privacy & Security**.
3. Прокрутите до раздела **Безопасность / Security**. Найдите сообщение о Collection Studio и нажмите **Всё равно открыть / Open Anyway**.

   ![Кнопка Open Anyway в разделе Privacy & Security](https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/macos-sequoia-system-settings-privacy-and-security-open-app-anyway.png)

4. Подтвердите **Открыть / Open**. При необходимости введите пароль пользователя Mac или используйте Touch ID.

macOS сохранит исключение для Collection Studio. В следующие разы приложение можно открывать двойным щелчком.

Скриншоты взяты из [Apple Support](https://support.apple.com/en-by/102445). На них показаны macOS Sequoia и пример **Example App**. На вашем Mac в сообщении будет название **Collection Studio**; положение и подписи кнопок зависят от версии и языка системы.

### Если возникли затруднения

| Что вы видите                           | Что сделать                                                                                                                                                                                       |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Кнопка «Всё равно открыть» отсутствует  | Снова попробуйте запустить приложение и вернитесь в настройки. По [инструкции Apple](https://support.apple.com/en-euro/guide/mac-help/mh40617/mac) кнопка доступна примерно час после блокировки. |
| Открытие запрещено на корпоративном Mac | Обратитесь к администратору: доступ определяется политикой организации.                                                                                                                           |
| Сообщение «приложение повреждено»       | Скачайте ZIP повторно и сверьте SHA-256 с файлом `SHA256SUMS.txt` в релизе. Если ошибка повторится, обратитесь к автору.                                                                          |
| Сообщение «повредит компьютер»          | Остановите запуск и обратитесь к автору приложения.                                                                                                                                               |

## Подключить Codex CLI

При первом открытии уже доступна встроенная библиотека. Для генерации выполните настройку:

1. Установите [Codex CLI](https://developers.openai.com/codex/cli/). Готовый нативный вариант работает самостоятельно.
2. Откройте Терминал и выполните `codex login`.
3. Выберите вход через ChatGPT.
4. В Collection Studio откройте **Настройки → Проверить подключение**.
5. Если CLI остался недоступен, укажите полный путь в поле **Путь к Codex CLI**, сохраните настройки и повторите проверку.

Проверка подтверждает запуск CLI и способ входа. Если CLI не отвечает, через 15 секунд появится инструкция для решения проблемы. Запросы генерации используют доступ к моделям, инструменту изображений и лимитам вашей учётной записи Codex.

## Собрать из исходников

Исходники доступны в [репозитории](https://github.com/bolotnikov/collection-studio). Версии Node.js и npm указаны в разделе [Сборка из исходников](../README.md#building-from-source).

1. Скачайте исходники и установите подходящую версию Node.js.
2. В корне проекта выполните `npm ci`.
3. Соберите приложение командой `npm run build`.
4. Запустите его командой `npm start`.

На Apple Silicon команда `npm run package:mac` также создаёт локальное приложение и универсальный ZIP.

Локальная сборка обычно запускается без запроса, связанного с карантином интернет-загрузки. К ней применяются настройки безопасности вашего Mac. Для генерации подключите Codex CLI и войдите через ChatGPT.
