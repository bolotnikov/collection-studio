# Первый запуск Collection Studio на другом Mac

Скачайте [универсальную сборку для Mac](https://github.com/bolotnikov/collection-studio/releases/latest/download/Collection-Studio-mac-universal.zip), распакуйте ZIP и перенесите `Collection Studio.app` в «Программы» (**Applications**). Для самого приложения отдельно устанавливать Node.js или Electron и собирать исходники не нужно. Библиотека референсов уже включена.

Требуется **macOS 13 Ventura или новее** на **Intel либо Apple Silicon**. В одном приложении находятся обе архитектуры. Старые версии macOS не поддерживаются: это ограничение используемого [Electron 45](https://www.electronjs.org/docs/latest/breaking-changes). Проверки упаковки и запуска не гарантируют совместимость с каждым физическим Mac, корпоративной политикой безопасности или будущей версией macOS.

## Если macOS не разрешает открыть приложение

Эта предварительная сборка имеет локальную ad-hoc подпись, но не подпись Apple Developer ID и не нотарификацию Apple. При первом открытии скачанного файла возможна системная проверка Gatekeeper. Это проверка приложения, а не ошибка «небезопасного подключения» к сети.

1. Попробуйте открыть **Collection Studio.app**. Если macOS сообщает, что не может проверить разработчика или отсутствие вредоносного ПО, закройте уведомление кнопкой **Готово / Done**. Не удаляйте приложение, если намерены продолжить.

   ![Пример уведомления macOS: Apple не может проверить приложение](https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/macos-sequoia-app-not-opened-could-not-verify-free-from-malware.png)

2. Если вы доверяете источнику файла, откройте ** → Системные настройки / System Settings → Конфиденциальность и безопасность / Privacy & Security**. Прокрутите до раздела **Безопасность / Security**.
3. Найдите сообщение о заблокированном **Collection Studio** и нажмите **Всё равно открыть / Open Anyway**. Название кнопки может немного отличаться в разных версиях macOS.

   ![Где находится Open Anyway в настройках Privacy & Security](https://cdsassets.apple.com/live/7WUAS350/images/macos/sequoia/macos-sequoia-system-settings-privacy-and-security-open-app-anyway.png)

4. Подтвердите **Открыть / Open**. При необходимости введите пароль пользователя Mac или подтвердите действие Touch ID. После добавления исключения приложение можно открывать обычным двойным щелчком.

Скриншоты выше предоставлены [Apple Support](https://support.apple.com/en-by/102445). Они показывают английский интерфейс macOS Sequoia и пример приложения **Example App**; в вашем уведомлении должно быть **Collection Studio**. Расположение элементов в Ventura, Sonoma и следующих версиях может отличаться.

Если кнопки нет, сначала повторите попытку открыть приложение: по [инструкции Apple](https://support.apple.com/en-euro/guide/mac-help/mh40617/mac) исключение доступно примерно в течение часа после блокировки. На корпоративном Mac его может запрещать администратор. Сообщения «приложение повреждено» или «повредит компьютер» не следует считать тем же уведомлением: скачайте архив повторно, сверьте SHA-256 из релиза и обратитесь к автору, если проблема повторяется. Не отключайте Gatekeeper целиком и не снимайте защиту рекурсивно со всех файлов.

## Если Codex CLI не установлен или вход не выполнен

Само приложение открывается, а встроенную библиотеку можно просматривать. Генерация отключена; на экране нового набора и в настройках показано, что требуется сделать.

1. Установите [Codex CLI](https://developers.openai.com/codex/cli/). Для готового нативного CLI не требуется Node.js.
2. Откройте Терминал и выполните `codex login`, выбрав вход через ChatGPT.
3. В приложении откройте **Настройки → Проверить подключение**. Если автоматический поиск не сработал, укажите полный путь в поле **Путь к Codex CLI**, сохраните настройки и повторите проверку.

Проверка подключения не генерирует изображения. Она проверяет локальную доступность CLI и способ входа; доступ к моделям, инструменту изображений и лимитам учётной записи проверяется при реальном обращении. Если CLI не отвечает, проверка завершается через 15 секунд с понятной инструкцией.

## Всегда можно собрать из исходников

Исходники доступны в [репозитории](https://github.com/bolotnikov/collection-studio). Следуйте разделу [Building from source](../README.md#building-from-source): установите указанную там версию Node.js, затем выполните `npm ci`, `npm run build` и `npm start`. `npm run package:mac` создаёт локальное приложение и универсальный ZIP; для упаковки сейчас используется Apple Silicon Mac.

Локальная сборка обычно не получает метку карантина скачанного из интернета ZIP, поэтому именно проверка первого запуска интернет-загрузки обычно не появляется. Это **не обещание отсутствия любых проверок macOS** и не замена правилам безопасности организации. Для генерации по-прежнему нужны Codex CLI, вход через ChatGPT и доступные лимиты.
