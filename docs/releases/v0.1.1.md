Collection Studio создаёт коллекции из десяти игровых карточек. Версия 0.1.1 добавляет проверку уникальности изображаемых предметов и людей, разнообразие цветового ритма и сайт документации.

## Что изменилось

- При планировании учитываются самостоятельные предметы и персонажи во всех наборах запуска. Повторяющиеся заявленные сущности отклоняются до генерации изображений.
- Цветовые схемы получают воспроизводимое разнообразие с учётом предыдущих наборов.
- При паузе интерфейс получает состояние проекта после сохранения соответствующего снимка.
- Обновлены значок приложения и оформление интерфейса.
- Опубликован [сайт документации](https://bolotnikov.github.io/collection-studio/) с руководством, описанием алгоритма и примерами коллекций.
- Задачи, исследование и решения в документации изложены в нейтральном стиле: «стояла задача», «были изучены», «были рассмотрены».
- Проверки, сборка приложения и публикация сайта выполняются через GitHub Actions.

## Установка

1. Скачайте `Collection-Studio-mac-universal.zip` из раздела Assets.
2. Распакуйте архив и перенесите `Collection Studio.app` в «Программы».
3. Откройте приложение. Если macOS запросит подтверждение, следуйте [инструкции первого запуска](https://github.com/bolotnikov/collection-studio/blob/main/docs/MACOS_FIRST_LAUNCH.md).

Архив содержит универсальное приложение для Intel и Apple Silicon, Electron, библиотеку референсов и `START-HERE.txt`. Требуется macOS 13 Ventura или новее. Сборка использует локальную подпись ad-hoc без нотарификации Apple.

Для генерации установите Codex CLI, выполните вход через ChatGPT и проверьте подключение в настройках приложения. Просмотр библиотеки доступен сразу после открытия.

## Проверки

- GitHub Actions выполняет TypeScript, ESLint, все автоматические тесты и сборку на macOS ARM64.
- Упаковка проверяет подпись, обе архитектуры исполняемого файла, нативные библиотеки изображений и подготовленные ресурсы.
- Перед публикацией проверяются ZIP и SHA-256. Контрольная сумма прилагается в `SHA256SUMS.txt`.
- Сайт проходит проверку типов, форматирования, сборку и проверку локальных ссылок, якорей и изображений с путём `/collection-studio/`.

Автоматические проверки используют подготовленные данные. Новая генерация изображений при выпуске не запускается.
